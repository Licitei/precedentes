Todas as capturas foram feitas em 19/11/2026. Cada página foi capturada duas vezes, com bytes e SHA-256 coincidentes; cada PDF também foi capturado duas vezes, com pares idênticos. CPFs encontrados em carimbos de assinatura foram substituídos por `[CPF omitido]`; capturas e PDFs permanecem privados.

Não se infere vigência, revogação, suspensão ou completude dos acervos municipais. As situações e notas são as que cada página e cada documento exibem literalmente.
